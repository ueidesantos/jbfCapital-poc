## ✨ Padrão Estabelecido

### Formato para Futuras Citações

**Fonte Única**:
```
Fonte: [Instituição] - [Nome do Documento], [Mês/Ano]
```

**Múltiplas Fontes**:
```
Fontes: [Instituição 1] ([Ano]), [Instituição 2] ([Ano]), [Instituição 3] ([Ano])
```

**Exemplos**:
- ✅ "Fonte: IBGE - PNAD Contínua, Set/2024"
