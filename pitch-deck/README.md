# 📊 JBF Capital - Pitch Deck Institucional

Este diretório contém todos os recursos necessários para criar e manter apresentações institucionais da JBF Capital, incluindo pitch decks para investidores, parceiros e comitês executivos.

## 📁 Estrutura de Arquivos

```
pitch-deck/
├── README.md                          # Este arquivo
├── presentation.html                  # Apresentação interativa (9 slides)
├── index.html                         # Página de visualização e recursos

│   ├── Screenshot_1.png
│   ├── Screenshot_2.png
│   ├── ...
```

## 🚀 Como Usar

### Opção 1: Apresentação Interativa (Recomendado)

1. Abra `presentation.html` em um navegador moderno
2. Use as teclas de seta ou os botões para navegar
3. Pressione F11 ou use o botão de tela cheia para modo apresentação
4. Apresente diretamente do navegador!

### Opção 2: Baixar os Slides

1. Os 9 slides estão disponíveis como imagens PNG em `imagens_exemplo/`
2. Screenshot_1.png até Screenshot_9.png
3. Use-os em PowerPoint, Keynote, Google Slides ou qualquer ferramenta de apresentação
4. Resolução aproximada: 1212x688 pixels

### Opção 3: Gerar PowerPoint (Original)

```bash
cd pitch-deck
python3 generate_pitch_deck.py
```

Este script gera um arquivo `JBF_Capital_Pitch_Deck.pptx` com slides de exemplo.

## 🎯 Dicas de Apresentação

### Para Investidores
- Foque nos slides de tração, modelo de negócio e resultados
- Destaque métricas financeiras e potencial de crescimento
- Prepare-se para perguntas sobre valuation e uso de capital

### Para Parceiros
- Enfatize benefícios mútuos e oportunidades de integração
- Mostre casos de sucesso e impacto no mercado
- Apresente facilidades técnicas e comerciais

### Para Clientes
- Foque nos benefícios e diferenciais competitivos
- Use cases de sucesso e testemunhos
- Demonstre facilidade de uso e valor entregue

## ✅ Checklist Pré-Apresentação

Antes de apresentar, verifique:

- [ ] Todos os slides carregam corretamente
- [ ] Navegação funciona (teclado e mouse)
- [ ] Modo tela cheia está disponível
- [ ] Projetor/tela está configurado corretamente
- [ ] Conexão de internet (se necessário)
- [ ] Backup da apresentação disponível
- [ ] Tempo de apresentação cronometrado
- [ ] Respostas para perguntas frequentes preparadas
