# 📊 JBF Capital - Pitch Deck Institucional

Este diretório contém todos os recursos necessários para criar e manter apresentações institucionais da JBF Capital, incluindo pitch decks para investidores, parceiros e comitês executivos.

## 📁 Estrutura de Arquivos

```
pitch-deck/
├── README.md                          # Este arquivo
├── IDENTIDADE_VISUAL.md               # Guia completo de identidade visual
├── STORYTELLING.md                    # Estrutura narrativa e storytelling (16 slides)
├── generate_pitch_deck.py             # Script Python para gerar PowerPoint
└── JBF_Capital_Pitch_Deck.pptx       # Apresentação PowerPoint gerada
```

## 🎯 Objetivo

Criar um pitch deck corporativo profissional e impactante que transmita:
- ✅ Credibilidade e solidez financeira
- ✅ Clareza estratégica
- ✅ Profissionalismo
- ✅ Inovação tecnológica
- ✅ Valores e cultura da empresa

## 📚 Documentação Disponível

### 1. IDENTIDADE_VISUAL.md

- 🎨 **Paleta de Cores**: Cores primárias, secundárias, complementares e de ação (com HEX/RGB)
- 🔤 **Tipografia**: Hierarquia de fontes, tamanhos e pesos

- 🖼️ **Diretrizes de Imagens**: Estilo fotográfico, ilustrações e ícones
- 🏢 **Posicionamento de Logotipo**: Regras de uso em diferentes contextos

- 📚 **Citações e Fontes**: Formatação de referências de dados
- ✅ **Checklist de Qualidade**: Verificações antes de finalizar

### 2. STORYTELLING.md
Estrutura completa do pitch deck (16 slides) contendo:

#### Slides Principais:
1. **Capa** - Apresentação da marca
2. **Contexto & Oportunidade** - Mercado e potencial (📚 com fontes de dados)
3. **Problema** - Dores do mercado (📚 com citação referenciada)
4. **Solução** - Como a JBF Capital resolve
5. **Proposta de Valor** - Benefícios claros

7. **Diferenciais Competitivos** - Vantagens únicas

#### 🆕 Slides de Arquitetura e Valores:
9. **Arquitetura Técnica** - Stack tecnológico, segurança, escalabilidade
10. **Arquitetura de Integração** - APIs, fluxo de integração, parceiros

Para cada slide há:
- ✅ Título sugerido
- ✅ Mensagem principal

- ✅ **Fontes de dados citadas (quando aplicável)**

## 🚀 Como Usar

### Opção 1: Gerar PowerPoint Automaticamente

```bash
cd pitch-deck
python3 generate_pitch_deck.py
```

Este script gera um arquivo `JBF_Capital_Pitch_Deck.pptx` com:
- ✅ 9 slides prontos com conteúdo de exemplo
- ✅ Identidade visual aplicada (cores, fontes, gradientes)
- ✅ Layouts profissionais
- ✅ Slides de Arquitetura (9 e 10)
- ✅ Slides de Valores (11 e 12)

**Slides incluídos no arquivo gerado:**
- Slide 1: Capa
- Slide 2: Contexto & Oportunidade
- Slide 3: Problema
- Slide 4: Solução
- Slide 9: Arquitetura Técnica ⚙️
- Slide 10: Arquitetura de Integração 🔄
- Slide 11: Valores da Empresa 💎
- Slide 12: Valor Agregado ao Cliente 💰
- Slide 16: Encerramento

### Opção 2: Criar Manualmente

1. Abra o PowerPoint ou Google Slides
2. Configure o tamanho do slide para 16:9 (padrão)
3. Consulte `IDENTIDADE_VISUAL.md` para cores e fontes
4. Siga a estrutura de `STORYTELLING.md` para cada slide
5. Use o arquivo gerado como referência visual

### Opção 3: Editar o Arquivo Gerado

1. Abra `JBF_Capital_Pitch_Deck.pptx`
2. Complete os slides restantes (5, 6, 7, 8, 13, 14, 15)
3. Adicione imagens reais e logos
4. Ajuste conteúdo conforme necessário
5. Revise usando o checklist em `IDENTIDADE_VISUAL.md`

## 📝 Customização

### Modificar o Script Python

Edite `generate_pitch_deck.py` para:
- Adicionar novos slides
- Modificar layouts
- Ajustar cores e fontes
- Incluir imagens personalizadas
- Alterar conteúdo

### Adicionar Logo

Para adicionar o logo da JBF Capital:
1. Coloque a imagem do logo no diretório `pitch-deck/`
2. Edite o script Python na função `add_footer()` ou crie uma função específica
3. Use `slide.shapes.add_picture()` para inserir a imagem

Exemplo:
```python
logo_path = "path/to/logo.png"
left = Inches(0.5)
top = Inches(7)
height = Inches(0.4)
slide.shapes.add_picture(logo_path, left, top, height=height)
```
