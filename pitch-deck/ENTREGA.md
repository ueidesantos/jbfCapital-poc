### Tipografia

- **Títulos**: Segoe UI Bold, 44-54pt
- **Subtítulos**: Segoe UI Semibold, 32-40pt
- **Corpo**: Segoe UI Regular, 16-20pt
- **Notas**: Segoe UI Regular, 12-14pt
